## Token Counting Methodology

The Haiku Protocol uses OpenAI's GPT-4 tokenizer (`cl100k_base` encoding) as the standard measure of compression effectiveness. This ensures compatibility with modern LLMs and provides consistent, reproducible token counts.

**Why cl100k_base?**
- GPT-4 and Claude 3+ use this encoding
- Optimal for technical documentation (handles code blocks, special characters)
- Consistent across different documents and domains
- Public reference implementation via `tiktoken` library

**Token Definition:**
A token is the smallest unit of text the model processes. Common patterns:
- Most English words: 1 token (e.g., "docker", "configure")
- Short words: 1 token (e.g., "to", "the", "is")
- Longer words: 2+ tokens (e.g., "configuration" → 2 tokens)
- Code and commands: variable (e.g., `git commit -m "message"` → ~8 tokens)
- Punctuation and whitespace: typically 1 token per element

## Metrics to Collect Per Document

### Primary Metrics

| Metric | Type | Description |
|--------|------|-------------|
| `character_count` | int | Total bytes (UTF-8) in document |
| `word_count` | int | Space-separated word count (using whitespace split) |
| `sentence_count` | int | Sentences (split on `.`, `!`, `?`) |
| `token_count` | int | Tokens via cl100k_base (tiktoken) |
| `unique_token_count` | int | Distinct token IDs in encoding |
| `avg_tokens_per_sentence` | float | token_count / sentence_count |
| `avg_tokens_per_word` | float | token_count / word_count |
| `content_density_score` | float | (token_count / word_count) × 10 |

### Content Analysis Metrics

| Metric | Type | Description |
|--------|------|-------------|
| `number_of_procedures` | int | Regex count of "Step", "Part", "Section" headers |
| `number_of_prerequisites` | int | Regex count of prerequisite mentions |
| `number_of_commands` | int | Count of backtick-enclosed commands |
| `number_of_warnings` | int | Count of "Warning", "Caution", "Note" blocks |
| `number_of_conditions` | int | Regex count of conditional keywords (if, else, when) |
| `number_of_cross_references` | int | Regex count of "see also", "refer to" markers |

## Complete Python Script: baseline_metrics.py

```python
#!/usr/bin/env python3
"""
Raw Metrics Collection for Haiku Protocol Benchmarking (v0.0.3b)

Reads three sample documents and computes comprehensive token and content metrics.
Outputs structured JSON to benchmarks/raw_metrics.json
"""

import json
import re
import sys
from pathlib import Path
from typing import Dict, Any, List

try:
    import tiktoken
except ImportError:
    print("ERROR: tiktoken not installed. Run: pip install tiktoken")
    sys.exit(1)

# Initialize GPT-4 tokenizer (cl100k_base encoding)
ENCODING = tiktoken.get_encoding("cl100k_base")

def count_tokens(text: str) -> int:
    """Count tokens using cl100k_base encoding."""
    return len(ENCODING.encode(text))

def get_unique_token_count(text: str) -> int:
    """Count unique token IDs in document."""
    tokens = ENCODING.encode(text)
    return len(set(tokens))

def count_sentences(text: str) -> int:
    """Count sentences by splitting on sentence-end markers."""
    sentences = re.split(r'[.!?]+', text)
    return len([s for s in sentences if s.strip()])

def count_procedures(text: str) -> int:
    """Count procedural markers (Step, Part, Section)."""
    return len(re.findall(r'\b(?:step|part|section)\s+\d+', text, re.IGNORECASE))

def count_prerequisites(text: str) -> int:
    """Count prerequisite markers."""
    return len(re.findall(r'\b(?:prerequisite|require|before|first|ensure)\b', text, re.IGNORECASE))

def count_commands(text: str) -> int:
    """Count backtick-enclosed code snippets/commands."""
    return len(re.findall(r'`[^`]+`', text))

def count_warnings(text: str) -> int:
    """Count warning, caution, and note blocks."""
    return len(re.findall(r'\b(?:warning|caution|note|important|critical)\b', text, re.IGNORECASE))

def count_conditions(text: str) -> int:
    """Count conditional keywords."""
    return len(re.findall(r'\b(?:if|else|when|unless|depending|otherwise)\b', text, re.IGNORECASE))

def count_cross_references(text: str) -> int:
    """Count cross-reference markers."""
    return len(re.findall(r'\b(?:see also|refer|reference|link|consult)\b', text, re.IGNORECASE))

def analyze_document(file_path: Path, tier: str) -> Dict[str, Any]:
    """
    Analyze a single document and return complete metrics dict.
    """
    # Read document
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            text = f.read()
    except Exception as e:
        return {"error": f"Failed to read {file_path}: {str(e)}"}

    # Basic counts
    char_count = len(text)
    word_count = len(text.split())
    sentence_count = count_sentences(text)
    token_count = count_tokens(text)
    unique_token_count = get_unique_token_count(text)

    # Derived metrics
    avg_tokens_per_sentence = round(token_count / sentence_count, 2) if sentence_count > 0 else 0
    avg_tokens_per_word = round(token_count / word_count, 2) if word_count > 0 else 0
    content_density_score = round((token_count / word_count) * 10, 2) if word_count > 0 else 0

    # Content analysis
    procedures = count_procedures(text)
    prerequisites = count_prerequisites(text)
    commands = count_commands(text)
    warnings = count_warnings(text)
    conditions = count_conditions(text)
    cross_references = count_cross_references(text)

    return {
        "tier": tier,
        "file_path": str(file_path),
        "metrics": {
            "character_count": char_count,
            "word_count": word_count,
            "sentence_count": sentence_count,
            "token_count": token_count,
            "unique_token_count": unique_token_count,
            "avg_tokens_per_sentence": avg_tokens_per_sentence,
            "avg_tokens_per_word": avg_tokens_per_word,
            "content_density_score": content_density_score,
        },
        "content_analysis": {
            "number_of_procedures": procedures,
            "number_of_prerequisites": prerequisites,
            "number_of_commands": commands,
            "number_of_warnings": warnings,
            "number_of_conditions": conditions,
            "number_of_cross_references": cross_references,
        },
    }

def main():
    """Main execution: analyze all three sample documents."""
    samples_dir = Path("benchmarks/samples")

    # Verify sample directory exists
    if not samples_dir.exists():
        print(f"ERROR: {samples_dir} not found. Run v0.0.3a first.")
        sys.exit(1)

    # Define sample files
    sample_files = [
        (samples_dir / "simple.md", "Simple"),
        (samples_dir / "medium.md", "Medium"),
        (samples_dir / "complex.md", "Complex"),
    ]

    # Analyze each document
    results = {
        "version": "0.0.3b",
        "encoding": "cl100k_base",
        "tokenizer": "tiktoken",
        "documents": [],
    }

    for file_path, tier in sample_files:
        if not file_path.exists():
            print(f"WARNING: {file_path} not found, skipping.")
            continue

        print(f"Analyzing {tier} sample ({file_path.name})...")
        metrics = analyze_document(file_path, tier)

        if "error" not in metrics:
            results["documents"].append(metrics)
            print(f"  ✓ Token count: {metrics['metrics']['token_count']}")
        else:
            print(f"  ✗ {metrics['error']}")

    # Write output JSON
    output_path = Path("benchmarks/raw_metrics.json")
    output_path.parent.mkdir(parents=True, exist_ok=True)

    with open(output_path, 'w', encoding='utf-8') as f:
        json.dump(results, f, indent=2)

    print(f"\n✓ Raw metrics saved to {output_path}")
    return results

if __name__ == "__main__":
    main()
```

## Verification: Token Count Sanity Check

Cross-check tiktoken results with OpenAI's online tokenizer:

```bash
# Step 1: Extract first 500 chars from each sample
head -c 500 benchmarks/samples/simple.md > /tmp/simple_excerpt.txt

# Step 2: Visit https://platform.openai.com/tokenizer
# Paste excerpt and verify token count matches tiktoken result

# Step 3: If discrepancy > 5%, investigate encoding issues
```

**Common Issues & Resolutions:**
- **Encoding Mismatch:** Ensure sample files are UTF-8 (not UTF-16 or Latin-1)
- **Line Ending Differences:** CRLF vs. LF may cause slight variations; normalize to LF
- **BOM (Byte Order Mark):** Some editors add invisible BOM; remove with: `sed -i '1s/^\xEF\xBB\xBF//' file.md`


## Limitations

- **Tokenizer Variations:** Different tokenizer versions (cl100k_base has minor updates) may produce counts differing by 1–2 tokens
- **Sentence Detection:** Simple regex-based splitting may miscount on ellipses (`...`), abbreviations, and multi-line sentences
- **Language-Specific:** Metrics are optimized for English procedural documentation; multilingual documents will produce skewed density scores
- **Code Block Artifacts:** Tokens in backticks are counted as part of document; very code-heavy documents will have inflated token counts relative to word count
