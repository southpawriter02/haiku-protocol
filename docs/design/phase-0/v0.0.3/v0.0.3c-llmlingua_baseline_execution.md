## Configuration Parameters

LLMLingua supports several configuration options. Use the following **default settings** for baseline consistency:

| Parameter | Default | Purpose |
|-----------|---------|---------|
| `compression_rate` | 0.5 | Target 50% of original tokens (50% reduction) |
| `target_token` | None | Use `compression_rate` instead of fixed target |
| `use_llmlingua2` | False | Use v1 algorithm (more stable than v2) |
| `context_budget` | -1 | Use all context (no truncation) |
| `target_context_budget` | None | Same as original; full preservation |
| `min_compress_ratio` | 0.5 | Don't compress below 50% of original |

**Rationale:**
- 50% compression rate represents a balanced target between token reduction and semantic preservation
- LLMlingua v1 is more stable and reproducible than v2 (beta)
- Full context preservation ensures fair comparison across document tiers

## Complete Python Script: llmlingua_baseline.py

```python
#!/usr/bin/env python3
"""
LLMLingua Baseline Execution for Haiku Protocol Benchmarking (v0.0.3c)

Runs LLMLingua compression on three sample documents with standard parameters.
Outputs compression results to benchmarks/llmlingua_baseline.json
"""

import json
import sys
import time
from pathlib import Path
from typing import Dict, Any, Optional, Tuple
import torch

try:
    from llmlingua import PromptCompressor
except ImportError:
    print("ERROR: llmlingua not installed. Run: pip install llmlingua")
    sys.exit(1)

# Configuration parameters
COMPRESSION_CONFIG = {
    "compression_rate": 0.5,
    "target_token": None,
    "use_llmlingua2": False,
    "context_budget": -1,
    "target_context_budget": None,
    "min_compress_ratio": 0.5,
}

def detect_gpu_availability() -> Tuple[bool, Optional[str]]:
    """
    Detect GPU availability and return (has_gpu, device_name).
    """
    if torch.cuda.is_available():
        device_name = torch.cuda.get_device_name(0)
        return True, device_name
    elif torch.backends.mps.is_available():
        return True, "Apple Metal Performance Shaders"
    else:
        return False, None

def initialize_compressor(device: str = "cuda") -> Optional[PromptCompressor]:
    """
    Initialize LLMLingua PromptCompressor.
    Falls back to CPU if CUDA not available.
    """
    try:
        compressor = PromptCompressor(
            model_name="microsoft/phi-2",  # Lightweight ranker model
            device_map=device,
        )
        return compressor
    except Exception as e:
        print(f"WARNING: Failed to initialize compressor on {device}: {str(e)}")
        if device == "cuda":
            print("Falling back to CPU...")
            try:
                compressor = PromptCompressor(
                    model_name="microsoft/phi-2",
                    device_map="cpu",
                )
                return compressor
            except Exception as e2:
                print(f"ERROR: Failed to initialize on CPU: {str(e2)}")
                return None

def compress_document(
    compressor: PromptCompressor,
    text: str,
    config: Dict[str, Any],
) -> Dict[str, Any]:
    """
    Compress a single document using LLMLingua.
    Returns metrics and compressed text.
    """
    start_time = time.time()

    try:
        result = compressor.compress_prompt(
            text,
            rate=config["compression_rate"],
            use_llmlingua2=config["use_llmlingua2"],
            context_budget=config["context_budget"],
            target_context_budget=config["target_context_budget"],
            min_compress_ratio=config["min_compress_ratio"],
        )
        elapsed = time.time() - start_time

        # Extract compression result
        compressed_text = result.get("compressed_prompt", "")
        compression_ratio = result.get("compression_ratio", 0.0)

        return {
            "success": True,
            "full_compressed_text": compressed_text,
            "compressed_text_preview": compressed_text[:200],
            "compressed_text_length": len(compressed_text),
            "compression_ratio": round(compression_ratio, 4),
            "execution_time_seconds": round(elapsed, 2),
            "semantic_preservation_notes": "Default LLMLingua v1 with 50% compression rate",
        }

    except Exception as e:
        elapsed = time.time() - start_time
        return {
            "success": False,
            "error": str(e),
            "execution_time_seconds": round(elapsed, 2),
        }

def analyze_llmlingua_results(
    file_path: Path,
    tier: str,
    compressor: PromptCompressor,
    device: str,
    has_gpu: bool,
    gpu_name: Optional[str],
) -> Dict[str, Any]:
    """
    Read sample document and run LLMLingua compression.
    Compressor is initialized once in main() and passed here.
    """
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            text = f.read()
    except Exception as e:
        return {
            "tier": tier,
            "file_path": str(file_path),
            "error": f"Failed to read document: {str(e)}",
        }

    # Count original tokens using tiktoken (consistent with v0.0.3b)
    try:
        import tiktoken
        encoding = tiktoken.get_encoding("cl100k_base")
        original_tokens = len(encoding.encode(text))
    except Exception:
        # Fallback to rough estimate if tiktoken unavailable
        original_tokens = int(len(text.split()) * 1.3)
        encoding = None

    # Compress document
    print(f"Compressing {tier} sample ({original_tokens} tokens)...")
    compression_result = compress_document(compressor, text, COMPRESSION_CONFIG)

    if compression_result["success"]:
        # Calculate compressed token count from FULL compressed text,
        # not just the preview (first 200 chars)
        full_compressed_text = compression_result.get("full_compressed_text", "")
        try:
            if encoding:
                compressed_tokens = len(encoding.encode(full_compressed_text))
            else:
                compressed_tokens = int(len(full_compressed_text.split()) * 1.3)
        except Exception:
            compressed_tokens = int(len(full_compressed_text.split()) * 1.3)

        return {
            "tier": tier,
            "file_path": str(file_path),
            "device_used": device,
            "gpu_available": has_gpu,
            "gpu_name": gpu_name,
            "metrics": {
                "original_tokens": original_tokens,
                "compressed_tokens": compressed_tokens,
                "compression_ratio": compression_result["compression_ratio"],
                "execution_time_seconds": compression_result["execution_time_seconds"],
            },
            "compressed_text_preview": compression_result["compressed_text_preview"],
            "semantic_preservation_notes": compression_result["semantic_preservation_notes"],
        }
    else:
        return {
            "tier": tier,
            "file_path": str(file_path),
            "error": compression_result["error"],
            "execution_time_seconds": compression_result["execution_time_seconds"],
            "device_used": device,
            "gpu_available": has_gpu,
        }

def main():
    """Main execution: run LLMLingua on all three samples."""
    samples_dir = Path("benchmarks/samples")

    # Verify raw metrics exist (required)
    raw_metrics_path = Path("benchmarks/raw_metrics.json")
    if not raw_metrics_path.exists():
        print("ERROR: benchmarks/raw_metrics.json not found.")
        print("Run v0.0.3b (Token Counting) first.")
        sys.exit(1)

    # Verify sample directory exists
    if not samples_dir.exists():
        print(f"ERROR: {samples_dir} not found. Run v0.0.3a first.")
        sys.exit(1)

    # Define sample files
    sample_files = [
        (samples_dir / "simple.md", "Simple"),
        (samples_dir / "medium.md", "Medium"),
        (samples_dir / "complex.md", "Complex"),
    ]

    # Detect GPU and initialize compressor ONCE (reuse across all documents)
    has_gpu, gpu_name = detect_gpu_availability()
    device = "cuda" if has_gpu else "cpu"

    print(f"Initializing LLMLingua on {device}...")
    compressor = initialize_compressor(device)

    if compressor is None:
        print("ERROR: Failed to initialize LLMLingua compressor.")
        sys.exit(1)

    # Record actual llmlingua version at execution time
    try:
        import llmlingua as _llm
        llmlingua_ver = getattr(_llm, "__version__", "unknown")
    except Exception:
        llmlingua_ver = "unknown"

    # Initialize results
    results = {
        "version": "0.0.3c",
        "llmlingua_version": llmlingua_ver,
        "configuration": COMPRESSION_CONFIG,
        "documents": [],
    }

    # Process each document (compressor shared across all)
    for file_path, tier in sample_files:
        if not file_path.exists():
            print(f"WARNING: {file_path} not found, skipping.")
            continue

        metrics = analyze_llmlingua_results(
            file_path, tier, compressor, device, has_gpu, gpu_name
        )
        results["documents"].append(metrics)

        if "error" not in metrics:
            print(f"  ✓ Compression ratio: {metrics['metrics']['compression_ratio']:.2%}")
        else:
            print(f"  ✗ {metrics['error']}")

    # Write output JSON
    output_path = Path("benchmarks/llmlingua_baseline.json")
    output_path.parent.mkdir(parents=True, exist_ok=True)

    with open(output_path, 'w', encoding='utf-8') as f:
        json.dump(results, f, indent=2)

    print(f"\n✓ LLMLingua baseline results saved to {output_path}")
    return results

if __name__ == "__main__":
    main()
```

## Fallback Plan: GPU-Limited Environments

If GPU is unavailable, LLMLingua can be slow or impossible. Implement this fallback strategy:

```
START: Check GPU availability
  │
  ├─► GPU available (CUDA/MPS)?
  │   └─ YES → Execute full LLMLingua compression (normal flow)
  │
  └─► NO GPU → Implement fallback
      │
      ├─► Simple sample only?
      │   ├─ YES → Execute on CPU (may take 2–5 min)
      │   └─ NO  → Use mock/estimated compression ratio
      │
      ├─► Medium & Complex samples
      │   ├─► Document limitation in JSON ("cpu_only_estimated": true)
      │   ├─► Estimate compression ratio as 0.45–0.55 (typical range)
      │   └─► Note: "LLMLingua execution skipped; estimated ratio based on token density"
      │
      └─► Proceed to v0.0.3d with mixed real/estimated results
          (Flag estimated results for post-analysis review)
```

## Limitations & Constraints

- **GPU Memory:** LLMLingua model loading requires ~2–4 GB VRAM. Some laptops may require CPU fallback.
- **Execution Time:** CPU execution can require 5–10 minutes per document; consider time constraints in scheduling.
- **Model Version:** The installed LLMLingua version is recorded at runtime for consistency; different versions may produce different compression ratios.
- **Semantic Preservation:** Automatic validation is difficult; manual review of compressed_text_preview recommended.
- **Reproducibility:** Results may vary slightly between runs due to model stochasticity (even with fixed seed).

## Troubleshooting

**Issue:** `ModuleNotFoundError: No module named 'llmlingua'`
**Solution:** Install with `pip install llmlingua`

**Issue:** CUDA out of memory (OOM) error
**Solution:** The script automatically falls back to CPU; alternatively, reduce document size or use CPU upfront for complex samples.

**Issue:** Compression ratio much higher than expected (e.g., 0.8 instead of 0.5)
**Solution:** Verify configuration parameters match defaults; check for model download failures; ensure sample text is valid procedural content.

**Issue:** Execution takes >10 minutes
**Solution:** CPU-only execution is slow; consider running on GPU system or using mock estimates.

**Issue:** `benchmarks/raw_metrics.json` not found
**Solution:** Run v0.0.3b (Token Counting) first to generate raw metrics.
