# v0.0.3 — Benchmarking Strategy

<aside>

**Version:** v0.0.3

**Parent:** v0.0.0 — Research & Discovery

**Duration:** 30-45 minutes

**Deliverable:** Baseline metrics for 3 sample documents (baseline_metrics.json)

## Objective

Establish **baseline measurements** before building anything. This version is broken into **sub-versions** for granular tracking across four measurement stages: document selection, raw metrics, LLMLingua baseline, and final reporting.

---

## Workflow: Benchmarking Pipeline

```
┌─────────────────────────────────────────────────────────────────┐
│                  BENCHMARKING PIPELINE                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   v0.0.3a: SAMPLE DOCUMENT SELECTION & CURATION                 │
│   ┌───────────────────────────────────────────────────────────┐ │
│   │ 1. Define selection criteria & complexity rubric           │ │
│   │ 2. Select 1 simple, 1 medium, 1 complex document          │ │
│   │ 3. Verify procedural content & token ranges                │ │
│   │ 4. Save to benchmarks/samples/                             │ │
│   └───────────────────────────────────────────────────────────┘ │
│                              │                                  │
│                              ▼                                  │
│   v0.0.3b: TOKEN COUNTING & RAW METRICS                         │
│   ┌───────────────────────────────────────────────────────────┐ │
│   │ 1. Run tiktoken (cl100k_base) on all 3 documents          │ │
│   │ 2. Collect char/word/sentence/token counts                 │ │
│   │ 3. Analyze content (procedures, prerequisites, commands)   │ │
│   │ 4. Save to benchmarks/raw_metrics.json                     │ │
│   └───────────────────────────────────────────────────────────┘ │
│                              │                                  │
│                              ▼                                  │
│   v0.0.3c: LLMLingua BASELINE EXECUTION                         │
│   ┌───────────────────────────────────────────────────────────┐ │
│   │ 1. Verify LLMLingua installation & GPU availability        │ │
│   │ 2. Run compression on all 3 documents                      │ │
│   │ 3. Record ratios, execution times, compressed text         │ │
│   │ 4. Save to benchmarks/llmlingua_baseline.json              │ │
│   └───────────────────────────────────────────────────────────┘ │
│                              │                                  │
│                              ▼                                  │
│   v0.0.3d: METRICS DOCUMENTATION & REPORTING                    │
│   ┌───────────────────────────────────────────────────────────┐ │
│   │ 1. Compile raw + LLMLingua metrics into final JSON         │ │
│   │ 2. Generate baseline_metrics.json                          │ │
│   │ 3. Draft README benchmark section                          │ │
│   │ 4. Validate results are promising for Phase 1              │ │
│   └───────────────────────────────────────────────────────────┘ │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Sample Documents

Select 3 documents of varying complexity (detailed in v0.0.3a):

### Document 1: Simple (50-100 tokens)

**Source:** Single procedure (e.g., "How to restart a service")

**Expected Compression:** 60-70%

### Document 2: Medium (200-500 tokens)

**Source:** Multi-step procedure with warnings

**Expected Compression:** 50-60%

### Document 3: Complex (1000+ tokens)

**Source:** Full tutorial or guide section

**Expected Compression:** 40-50%
