## Data Compilation Strategy

The final baseline_metrics.json combines two independent metric sources:

```
┌──────────────────────────────────────┐
│   raw_metrics.json (v0.0.3b)         │
│ (Token counts, content analysis)      │
└──────────┬───────────────────────────┘
           │
           ├──────────────────────────────────┐
           │  MERGE & COMBINE                 │
           │  (Document-by-document)          │
           │                                  │
           └──────────────────────────────────┘
           │
┌──────────┴───────────────────────────┐
│ llmlingua_baseline.json (v0.0.3c)    │
│ (Compression results)                 │
└──────────────────────────────────────┘
           │
           ▼
┌──────────────────────────────────────┐
│ baseline_metrics.json (v0.0.3d)      │
│ (Complete authoritative baseline)     │
└──────────────────────────────────────┘
```

**Merge Logic:**
1. Read both JSON files
2. Iterate through raw_metrics documents by tier (Simple, Medium, Complex)
3. Find matching tier in llmlingua results
4. Combine into single document record with both metric sets
5. Add derived fields (expected Haiku targets, analysis notes)
6. Write consolidated JSON

## Python Script: Metrics Compilation

```python
#!/usr/bin/env python3
"""
Metrics Compilation & Documentation for Haiku Protocol Benchmarking (v0.0.3d)

Merges raw_metrics.json and llmlingua_baseline.json into consolidated baseline_metrics.json.
Generates markdown reporting section for README.
"""

import json
import sys
from pathlib import Path
from typing import Dict, Any, List, Optional
from datetime import datetime

# Expected compression targets for Haiku Protocol
HAIKU_TARGETS = {
    "Simple": {"min": 0.30, "max": 0.40, "description": "30–40% of original tokens"},
    "Medium": {"min": 0.40, "max": 0.50, "description": "40–50% of original tokens"},
    "Complex": {"min": 0.45, "max": 0.55, "description": "45–55% of original tokens"},
}

def load_json_file(path: Path) -> Optional[Dict[str, Any]]:
    """Load and parse JSON file with error handling."""
    try:
        with open(path, 'r', encoding='utf-8') as f:
            return json.load(f)
    except FileNotFoundError:
        print(f"ERROR: {path} not found.")
        return None
    except json.JSONDecodeError as e:
        print(f"ERROR: Invalid JSON in {path}: {str(e)}")
        return None

def merge_metrics(
    raw_metrics: Dict[str, Any],
    llmlingua_results: Dict[str, Any],
) -> Optional[Dict[str, Any]]:
    """
    Merge raw_metrics and llmlingua_results into consolidated baseline_metrics.
    """
    if not raw_metrics.get("documents") or not llmlingua_results.get("documents"):
        print("ERROR: Missing documents in one or both metric files.")
        return None

    # Create tier-based lookup for LLMLingua results
    llmlingua_by_tier = {}
    for doc in llmlingua_results["documents"]:
        tier = doc.get("tier")
        if tier:
            llmlingua_by_tier[tier] = doc

    # Merge documents
    merged_documents = []

    for raw_doc in raw_metrics["documents"]:
        tier = raw_doc.get("tier")
        llmlingua_doc = llmlingua_by_tier.get(tier)

        if not llmlingua_doc:
            print(f"WARNING: No LLMLingua results found for {tier} tier.")
            continue

        # Extract LLMLingua metrics
        llmlingua_metrics = llmlingua_doc.get("metrics", {})

        # Calculate expected Haiku targets
        original_tokens = raw_doc.get("metrics", {}).get("token_count", 0)
        llmlingua_ratio = llmlingua_metrics.get("compression_ratio", 0.0)
        haiku_target = HAIKU_TARGETS.get(tier, {})

        # Estimate improvement needed
        improvement_vs_llmlingua = round(
            (llmlingua_ratio - haiku_target["min"]) * 100, 1
        ) if haiku_target else 0

        # Merged document
        merged_doc = {
            "tier": tier,
            "source_file": raw_doc.get("file_path", ""),
            "raw_metrics": raw_doc.get("metrics", {}),
            "content_analysis": raw_doc.get("content_analysis", {}),
            "llmlingua_baseline": {
                "compression_ratio": llmlingua_metrics.get("compression_ratio", 0.0),
                "original_tokens": llmlingua_metrics.get("original_tokens", 0),
                "compressed_tokens": llmlingua_metrics.get("compressed_tokens", 0),
                "execution_time_seconds": llmlingua_metrics.get("execution_time_seconds", 0),
            },
            "haiku_protocol_targets": {
                "target_compression_ratio_min": haiku_target.get("min", 0.0),
                "target_compression_ratio_max": haiku_target.get("max", 0.0),
                "target_description": haiku_target.get("description", ""),
                "improvement_vs_llmlingua_percent": improvement_vs_llmlingua,
            },
            "analysis_notes": (
                f"LLMLingua achieves {llmlingua_ratio:.1%} compression. "
                f"Haiku Protocol should target {haiku_target.get('description', 'N/A')}. "
                f"Potential improvement: {improvement_vs_llmlingua}% reduction."
            ),
        }

        merged_documents.append(merged_doc)

    # Create consolidated baseline metrics
    baseline_metrics = {
        "version": "0.0.3d",
        "timestamp": datetime.utcnow().isoformat() + "Z",
        "description": "Consolidated baseline metrics: raw token counts + LLMLingua compression results + Haiku Protocol targets",
        "encoding": "cl100k_base",
        "tokenizer": "tiktoken",
        "raw_metrics_source": f"v{raw_metrics.get('version', 'unknown')}",
        "llmlingua_metrics_source": f"v{llmlingua_results.get('version', 'unknown')}",
        "llmlingua_configuration": llmlingua_results.get("configuration", {}),
        "documents": merged_documents,
    }

    return baseline_metrics

def generate_markdown_report(baseline_metrics: Dict[str, Any]) -> str:
    """Generate markdown report section for README."""
    if not baseline_metrics or not baseline_metrics.get("documents"):
        return "# Baseline Metrics\n\n*No baseline metrics available.*\n"

    report = """# Baseline Metrics

## Overview

The Haiku Protocol is benchmarked against three representative procedural documents of varying complexity. Baseline measurements establish compression targets for v1 development.

### Metrics Collection Pipeline

1. **Raw Metrics (v0.0.3b):** Token counts and content analysis using GPT-4 tokenizer (cl100k_base)
2. **LLMLingua Baseline (v0.0.3c):** Parameter-efficient compression using established baseline tool
3. **Consolidated (v0.0.3d):** Merged metrics with Haiku Protocol targets for comparison

---

## Baseline Results Summary

"""

    # Create summary table
    report += "| Document | Tokens | LLMLingua Ratio | Haiku Target | Potential Gain |\n"
    report += "|----------|--------|-----------------|--------------|----------------|\n"

    for doc in baseline_metrics["documents"]:
        tier = doc.get("tier", "Unknown")
        raw_tokens = doc.get("raw_metrics", {}).get("token_count", "N/A")
        llmlingua_ratio = doc.get("llmlingua_baseline", {}).get("compression_ratio", 0.0)
        haiku_min = doc.get("haiku_protocol_targets", {}).get("target_compression_ratio_min", 0.0)
        improvement = doc.get("haiku_protocol_targets", {}).get("improvement_vs_llmlingua_percent", 0)

        haiku_target_str = f"{haiku_min:.0%}–{doc.get('haiku_protocol_targets', {}).get('target_compression_ratio_max', 0.0):.0%}"

        report += (
            f"| {tier:<12} | {raw_tokens:<6} | {llmlingua_ratio:>6.1%} | "
            f"{haiku_target_str:<12} | {improvement:>+6.1f}% |\n"
        )

    report += "\n---\n\n## Detailed Results\n\n"

    # Document-by-document details
    for doc in baseline_metrics["documents"]:
        tier = doc.get("tier", "Unknown")
        report += f"### {tier} Tier\n\n"

        # Raw metrics
        raw = doc.get("raw_metrics", {})
        report += "**Raw Metrics:**\n"
        report += f"- Character Count: {raw.get('character_count', 'N/A')}\n"
        report += f"- Word Count: {raw.get('word_count', 'N/A')}\n"
        report += f"- Token Count: {raw.get('token_count', 'N/A')}\n"
        report += f"- Sentence Count: {raw.get('sentence_count', 'N/A')}\n"
        report += f"- Content Density: {raw.get('content_density_score', 'N/A')}\n\n"

        # Content analysis
        content = doc.get("content_analysis", {})
        report += "**Content Analysis:**\n"
        report += f"- Procedures: {content.get('number_of_procedures', 'N/A')}\n"
        report += f"- Prerequisites: {content.get('number_of_prerequisites', 'N/A')}\n"
        report += f"- Commands: {content.get('number_of_commands', 'N/A')}\n"
        report += f"- Warnings/Notes: {content.get('number_of_warnings', 'N/A')}\n"
        report += f"- Conditions: {content.get('number_of_conditions', 'N/A')}\n\n"

        # LLMLingua results
        llm = doc.get("llmlingua_baseline", {})
        report += "**LLMLingua Compression:**\n"
        report += f"- Compression Ratio: {llm.get('compression_ratio', 'N/A'):.1%}\n"
        report += f"- Original Tokens: {llm.get('original_tokens', 'N/A')}\n"
        report += f"- Compressed Tokens: {llm.get('compressed_tokens', 'N/A')}\n"
        report += f"- Execution Time: {llm.get('execution_time_seconds', 'N/A')}s\n\n"

        # Haiku targets
        haiku = doc.get("haiku_protocol_targets", {})
        report += "**Haiku Protocol Target:**\n"
        report += f"- Target Compression: {haiku.get('target_description', 'N/A')}\n"
        report += f"- Improvement vs. LLMLingua: {haiku.get('improvement_vs_llmlingua_percent', 'N/A')}%\n\n"

        # Analysis notes
        report += f"**Notes:** {doc.get('analysis_notes', 'N/A')}\n\n"

    report += """---

## Interpretation & Next Steps

### Baseline Performance

- **Simple documents:** LLMLingua achieves ~50% compression
- **Medium documents:** LLMLingua achieves ~49% compression
- **Complex documents:** LLMLingua achieves ~47% compression

**Observation:** Larger documents compress more efficiently (lower final ratio), suggesting hierarchical structure and redundancy increase with document size.

### Haiku Protocol Targets

The Haiku Protocol aims to outperform LLMLingua by leveraging Controlled Natural Language (CNL) compression:

- **Simple:** Reduce from ~50% (LLMLingua) to 35–40% (Haiku) = 10–15% additional compression
- **Medium:** Reduce from ~49% (LLMLingua) to 40–50% (Haiku) = up to 9% additional compression
- **Complex:** Reduce from ~47% (LLMLingua) to 45–55% (Haiku) = potential 2–5% additional compression

### Quality Assurance

Baseline metrics serve as a checkpoint for:
1. Verifying v1 implementation produces comparable or better compression
2. Detecting performance regressions in future versions
3. Establishing empirical targets for optimization efforts
4. Comparing across different procedural document domains

### Files & Artifacts

All baseline metrics are preserved in `benchmarks/`:

```
benchmarks/
├── samples/
│   ├── simple.md           (Raw sample: ~89 tokens)
│   ├── medium.md           (Raw sample: ~287 tokens)
│   └── complex.md          (Raw sample: ~1047 tokens)
├── raw_metrics.json        (Token counts & content analysis)
├── llmlingua_baseline.json (LLMLingua compression results)
└── baseline_metrics.json   (Consolidated authoritative baseline)
```

"""

    return report

def main():
    """Main execution: merge metrics and generate reports."""
    # Load source metrics
    raw_metrics_path = Path("benchmarks/raw_metrics.json")
    llmlingua_path = Path("benchmarks/llmlingua_baseline.json")

    print("Loading raw metrics...")
    raw_metrics = load_json_file(raw_metrics_path)

    print("Loading LLMLingua results...")
    llmlingua_results = load_json_file(llmlingua_path)

    if not raw_metrics or not llmlingua_results:
        print("ERROR: Failed to load required metric files.")
        sys.exit(1)

    # Merge metrics
    print("Merging metrics...")
    baseline_metrics = merge_metrics(raw_metrics, llmlingua_results)

    if not baseline_metrics:
        print("ERROR: Failed to merge metrics.")
        sys.exit(1)

    # Write consolidated baseline
    output_path = Path("benchmarks/baseline_metrics.json")
    output_path.parent.mkdir(parents=True, exist_ok=True)

    with open(output_path, 'w', encoding='utf-8') as f:
        json.dump(baseline_metrics, f, indent=2)

    print(f"✓ Consolidated baseline metrics saved to {output_path}")

    # Generate markdown report
    markdown_report = generate_markdown_report(baseline_metrics)

    # Save report to file
    report_path = Path("BASELINE_METRICS_REPORT.md")
    with open(report_path, 'w', encoding='utf-8') as f:
        f.write(markdown_report)

    print(f"✓ Markdown report saved to {report_path}")

    # Also output to stdout for review
    print("\n" + "=" * 70)
    print("BASELINE METRICS REPORT")
    print("=" * 70)
    print(markdown_report)

    return baseline_metrics

if __name__ == "__main__":
    main()
```

"""
Standalone markdown report generator from baseline_metrics.json

import json

    """
    Generate markdown report from existing baseline_metrics.json.

    compile_metrics.py script (above). For standalone usage, copy
    that function here or import it from the scripts/ module.

    with open(baseline_json_path, 'r') as f:

    # Reuse the generate_markdown_report function defined in

## Limitations & Constraints

- **JSON Merge:** Assumes one-to-one tier matching between raw_metrics and llmlingua results; if tiers mismatch, documents are skipped with warning
- **Timestamp:** ISO 8601 format with UTC timezone; may differ from local execution time
- **Paths:** JSON uses relative paths; adjust as needed if directory structure differs
- **Floating-Point Precision:** Calculated percentages rounded to 1 decimal place

## Troubleshooting

**Issue:** `baseline_metrics.json` is empty or missing documents
**Solution:** Verify both raw_metrics.json and llmlingua_baseline.json exist and contain valid data; check tier names match exactly.

**Issue:** Token count discrepancies between raw_metrics and llmlingua_baseline
**Solution:** This may indicate tokener version differences or document encoding issues; document discrepancy in Decision Log and proceed if <5%.

**Issue:** Haiku targets seem unrealistic
**Solution:** Review improvement_vs_llmlingua_percent; adjust HAIKU_TARGETS constants if baselines changed.

**Issue:** BASELINE_METRICS_REPORT.md not generated
**Solution:** Ensure script completes fully; verify write permissions in output directory.
