## Research Questions

Answer these questions through your literature review:

1. **What compression ratios have been achieved?**
    - Target: Document best-in-class metrics (v0.0.1a)
2. **What approaches exist?**
    - Extractive (remove tokens)
    - Abstractive (rewrite content)
    - Hybrid (our approach) (v0.0.1b)
3. **What are the failure modes?**
    - Semantic drift
    - Information loss
    - Parsing errors (v0.0.1a, v0.0.1b)
4. **What gaps exist?**
    - Our hypothesis: No one has combined IA principles with compression (v0.0.1c, v0.0.1d)
