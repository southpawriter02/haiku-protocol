## Objective

Design the **Controlled Natural Language (CNL)** grammar that powers the Haiku Protocol. This is the core intellectual property of the project. This version is broken into **sub-versions** for granular tracking across four design stages: pattern analysis, operator design, grammar formalization, and validation rules.

## Grammar Rules (BNF-style) — Base Specification

Extended in v0.0.2c to include all operators from v0.0.2b:

```
<haiku>        ::= <statement> (';' <statement>)*
<statement>    ::= <action> | <condition> | <warning> | <reference>
<action>       ::= 'Action:' <identifier> <dependency>? <execution>?
<dependency>   ::= 'REQUIRES' <state> (',' <state>)*
<state>        ::= 'State:' <identifier>
<execution>    ::= '->' 'EXEC:' <command>
<condition>    ::= 'IF:' <identifier> 'THEN:' <action> ('ELSE:' <action>)?
<warning>      ::= 'WARN:' <identifier> '->' <identifier>
<identifier>   ::= [A-Za-z_][A-Za-z0-9_]*
<command>      ::= [^\s;]+
```

## Example Transformations

### Example 1: Simple Procedure

**Original:**

> "To restart the server, first save your configuration, then run the restart command."
>

**Haiku:**

```
Action:Restart_Server REQUIRES State:Config_Saved -> EXEC:restart_cmd
```

### Example 2: Conditional Procedure

**Original:**

> "If the deployment fails, check the logs. If logs show a timeout, increase the timeout value and retry."
>

**Haiku:**

```
IF:Deploy_Fail THEN:Action:Check_Logs; IF:Timeout_Error THEN:Action:Increase_Timeout -> Action:Retry
```

### Example 3: Multi-step with Warning

**Original:**

> "Before upgrading the database, create a backup. Warning: Skipping the backup may result in data loss. After backup, run the migration script and verify the schema."
>

**Haiku:**

```
Action:Upgrade_DB REQUIRES State:Backup_Complete; WARN:Skip_Backup->Data_Loss; EXEC:run_migration -> VERIFY:Schema_Valid
```
