## Objective

Analyze 10+ real-world procedural documentation sources to extract recurring structural patterns and semantic elements. Develop a comprehensive taxonomy of language patterns that will inform operator design, establishing empirical grounding for the CNL grammar specification.

---

## Corpus Selection Strategy

The foundation of the Haiku Protocol rests on understanding how procedural knowledge is naturally communicated. We must systematically collect and analyze documents that contain instructional, procedural, or operational content.

### Approved Document Categories

| Category | Examples | Source |
|----------|----------|--------|
| Man Pages | `man systemctl`, `man postgresql` | Linux/Unix systems |
| README Files | Setup instructions, quick starts | GitHub repositories |
| API Documentation | REST/GraphQL endpoint docs | AWS, GCP, OpenAI |
| Runbooks | On-call procedures, incident response | SRE documentation |
| Installation Guides | Multi-step deployment procedures | Software distributions |
| Troubleshooting Guides | Diagnostic + remediation steps | Knowledge bases |
| Tutorials | Step-by-step learning guides | Official docs, blogs |
| Release Notes | Migration/upgrade procedures | Version documentation |

### Exclusion Criteria

- Creative/narrative documentation
- Marketing or promotional content
- Non-English documentation
- Audio/video transcripts
- Purely conceptual (non-procedural) documentation

## Semantic Categories to Identify

### 1. **Actions** (Procedural Verbs/Commands)
*Imperative statements that perform work*

**Recognition Markers:** start, run, execute, apply, create, delete, install, build, deploy, configure, restart, reload, verify, check, test, list, get, post, put

**Example from corpus:** "Build the Docker image: docker build -t myapp:latest ."

**Frequency in corpus:** ~35% of sentences

> **Note:** These frequency distributions are hypothesized based on manual inspection of sample documents. Actual frequencies will be measured when this task is executed using the `PatternExtractor` class.

---

### 2. **States** (Preconditions & Postconditions)
*Conditions that must exist before or after an action*

**Recognition Markers:** ensure, must be, should be, verify (as check), confirm, is (descriptive), exists, enabled, disabled, configured

**Example from corpus:** "Ensure the data directory exists and is owned by the postgres user."

**Frequency in corpus:** ~18% of sentences

---

### 3. **Dependencies** (Ordering & Requirements)
*Explicit sequencing or prerequisite constraints*

**Recognition Markers:** first, then, after, before, once, until, requires, depends on, prerequisite

**Example from corpus:** "First ensure the data directory exists... Then start the server..."

**Frequency in corpus:** ~22% of sentences

---

### 4. **Warnings** (Consequences & Risks)
*Cautionary statements about failure modes or irreversible actions*

**Recognition Markers:** WARNING, WARN, caution, be careful, do not, never, risk, danger, irreversible, will lose, data loss, downtime

**Example from corpus:** "WARNING: This will delete ALL cached data. Coordinate with team beforehand."

**Frequency in corpus:** ~8% of sentences

---

### 5. **Conditions** (Branching & If-Then Logic)
*Branching paths based on observation or test result*

**Recognition Markers:** if, then, else, otherwise, in case, when, unless, on error, if not, assuming

**Example from corpus:** "If migration fails, restore from backup. If tests fail, revert."

**Frequency in corpus:** ~12% of sentences

---

### 6. **Verifications** (Checks & Validations)
*Tests that confirm successful completion of prior action*

**Recognition Markers:** verify, validate, confirm, check, test, ensure, assert, should show, should return, expect

**Example from corpus:** "Verify configuration: aws s3api get-bucket-versioning --bucket mybucket"

**Frequency in corpus:** ~14% of sentences

---

### 7. **References** (Cross-References & Links)
*Pointers to other documents, sections, or procedures*

**Recognition Markers:** see, refer to, for more info, documentation, section, guide, procedure, link to, follow

**Example from corpus:** "If migration fails, see Rollback Procedure."

**Frequency in corpus:** ~5% of sentences

---

### 8. **Metadata** (Version, Author, Timestamp, Context)
*Annotations about the document itself*

**Recognition Markers:** version, author, date, updated, prerequisites, requirements, applies to, compatible with

**Example from corpus:** "Prerequisites: Python 3.9+ and pip installed."

**Frequency in corpus:** ~6% of sentences

## Pattern Extraction Python Script

```python
#!/usr/bin/env python3
"""
Pattern Extraction Tool for Haiku Protocol v0.0.2a

Assists in categorizing procedural text into semantic patterns.
Input: Raw procedural document text
Output: Frequency counts, categorized excerpts, proposed operators
"""

import re
from collections import defaultdict
from typing import List, Dict, Tuple

class PatternExtractor:
    def __init__(self):
        self.patterns = {
            "Actions": re.compile(
                r'\b(start|run|execute|apply|create|delete|install|build|deploy|'
                r'configure|restart|reload|verify|check|test|list|get|post|put)\b',
                re.IGNORECASE
            ),
            "States": re.compile(
                r'\b(ensure|must be|should be|verify|confirm|is|exists|'
                r'enabled|disabled|configured)\b',
                re.IGNORECASE
            ),
            "Dependencies": re.compile(
                r'\b(first|then|after|before|once|until|requires|depends|prerequisite)\b',
                re.IGNORECASE
            ),
            "Warnings": re.compile(
                r'\b(WARNING|WARN|caution|be careful|do not|never|risk|danger|'
                r'irreversible|will lose|data loss)\b',
                re.IGNORECASE
            ),
            "Conditions": re.compile(
                r'\b(if|then|else|otherwise|in case|when|unless|on error)\b',
                re.IGNORECASE
            ),
            "Verifications": re.compile(
                r'\b(verify|validate|confirm|check|test|assert|'
                r'should show|should return|expect)\b',
                re.IGNORECASE
            ),
            "References": re.compile(
                r'\b(see|refer to|for more|documentation|section|guide|'
                r'procedure|link|follow)\b',
                re.IGNORECASE
            ),
            "Metadata": re.compile(
                r'\b(version|author|date|updated|prerequisites|requirements|'
                r'applies to|compatible)\b',
                re.IGNORECASE
            ),
        }
        self.frequencies = defaultdict(int)
        self.examples = defaultdict(list)

    def extract_patterns(self, text: str) -> Dict:
        """Extract patterns from procedural text."""
        sentences = re.split(r'[.!?]+', text)
        total_sentences = len([s for s in sentences if s.strip()])

        for sentence in sentences:
            if not sentence.strip():
                continue

            for category, pattern in self.patterns.items():
                if pattern.search(sentence):
                    self.frequencies[category] += 1
                    if len(self.examples[category]) < 3:
                        self.examples[category].append(sentence.strip())

        return self._format_results(total_sentences)

    def _format_results(self, total: int) -> Dict:
        """Format results as frequency percentages."""
        return {
            "frequencies": {
                cat: f"{(count/total*100):.1f}%"
                for cat, count in sorted(
                    self.frequencies.items(),
                    key=lambda x: x[1],
                    reverse=True
                )
            },
            "examples": dict(self.examples),
            "total_sentences_analyzed": total,
        }

# Usage example:
if __name__ == "__main__":
    sample_doc = """
    WARNING: This procedure requires maintenance window.
    First back up the database. Then stop application processes.
    Run migration script version 2.1.0. If migration fails, restore from backup.
    Verify schema integrity using validation script.
    See Rollback Procedure for error recovery.
    Prerequisites: Python 3.9 and backup completed.
    """

    extractor = PatternExtractor()
    results = extractor.extract_patterns(sample_doc)

    print("Pattern Frequencies:")
    for cat, freq in results["frequencies"].items():
        print(f"  {cat}: {freq}")
```

## Pattern Classification Decision Tree

```
START: Read sentence/phrase
   │
   ├─→ Contains action verb (run, create, execute)?
   │   └─→ YES: ACTIONS
   │
   ├─→ Describes required state/precondition (must be, ensure, exists)?
   │   └─→ YES: STATES
   │
   ├─→ Specifies ordering (first, then, after, before)?
   │   └─→ YES: DEPENDENCIES
   │
   ├─→ Warning/danger markers (WARNING, risk, irreversible)?
   │   └─→ YES: WARNINGS
   │
   ├─→ Conditional branch (if, then, else, when)?
   │   └─→ YES: CONDITIONS
   │
   ├─→ Validation/check (verify, confirm, test, expect)?
   │   └─→ YES: VERIFICATIONS
   │
   ├─→ Cross-reference (see, refer, documentation, link)?
   │   └─→ YES: REFERENCES
   │
   └─→ Meta-information (version, author, prerequisites)?
       └─→ YES: METADATA

AMBIGUITY RESOLUTION:
   If sentence matches multiple categories:
   1. Check if "verify" appears → prefer VERIFICATIONS over ACTIONS
   2. Check if "if/then" appears → prefer CONDITIONS
   3. Check if "then/after" appears → prefer DEPENDENCIES over ACTIONS
   4. Otherwise → assign PRIMARY category by first match
```
