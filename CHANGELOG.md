### Fixed

- Token count discrepancy between `llmlingua_baseline.json` and `raw_metrics.json` — `analyze_llmlingua_results()` now accepts `raw_metrics_token_count` parameter and `run_baseline()` loads authoritative token counts from `raw_metrics.json` (v0.0.3b output) instead of re-counting locally, ensuring Simple=101, Medium=443, Complex=1589 match upstream measurements exactly (v0.0.3c)
