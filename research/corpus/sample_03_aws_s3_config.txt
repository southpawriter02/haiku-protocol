Create an S3 bucket: aws s3api create-bucket --bucket mybucket --region us-east-1
Enable versioning: aws s3api put-bucket-versioning --bucket mybucket --versioning-configuration Status=Enabled
Block public access: aws s3api put-public-access-block --bucket mybucket --public-access-block-configuration "BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true"
Verify configuration: aws s3api get-bucket-versioning --bucket mybucket
